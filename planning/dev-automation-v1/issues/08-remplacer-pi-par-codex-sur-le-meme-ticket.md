# 08: Remplacer Pi par Codex sur le même ticket

**What to build:** Un mainteneur choisit Codex à la place de Pi pour un ticket équivalent et obtient le même contrat observable de résultats et de publication.

**Blocked by:** 07 — Implémenter un premier ticket avec Pi

**Status:** ready-for-agent

- [ ] Le dépôt appelant peut sélectionner Codex par sa configuration approuvée sans modifier le contrôleur.
- [ ] Codex produit le même format de résultats validables et une PR liée au ticket.
- [ ] Les permissions, la sandbox et le publisher restent identiques quel que soit le moteur.

**Traçabilité :** user stories US-51 ; tests T-10.
