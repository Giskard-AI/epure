# 11: Router une issue vers les skills Matt Pocock adaptés

**What to build:** Depuis une même issue, un agent choisit clarification, exploration des décisions ou formalisation selon l’incertitude du besoin, tout en laissant visibles les questions auxquelles l’humain doit répondre.

**Blocked by:** 10 — Traiter les commentaires dans l’ordre une fois chacun

**Status:** ready-for-agent

- [ ] Les demandes floues passent par le parcours de clarification ou Wayfinder avant la rédaction de tickets.
- [ ] Les réponses sont posées dans l’issue, reprennent le glossaire du domaine et ne réinterrogent pas une décision déjà établie.
- [ ] Les versions des skills intégrés sont identifiables et leurs licences/attributions sont conservées.

**Traçabilité :** user stories US-24, US-25 ; tests T-3.
