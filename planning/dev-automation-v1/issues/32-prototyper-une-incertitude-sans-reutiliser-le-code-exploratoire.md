# 32: Prototyper une incertitude sans réutiliser le code exploratoire

**What to build:** Lorsqu’une question de design résiste à la discussion, un agent produit un prototype démontrable, des captures et une conclusion de conception à réinjecter dans la spec.

**Blocked by:** 31 — Élaborer un design Impeccable dans l’entretien de planification

**Status:** ready-for-agent

- [ ] Une question incertaine peut déclencher un prototype isolé ; un simple changement clair n’impose pas de prototype.
- [ ] Les résultats sont liés à l’issue en artifacts/captures et accompagnés des décisions tirées des essais.
- [ ] L’implémentation productrice démarre depuis la base approuvée, sans copier automatiquement le code du prototype.

**Traçabilité :** user stories US-36, US-37, US-38, US-39 ; tests T-26.
