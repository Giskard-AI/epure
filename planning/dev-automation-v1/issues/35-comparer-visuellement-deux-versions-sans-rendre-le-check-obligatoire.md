# 35: Comparer visuellement deux versions sans rendre le check obligatoire

**What to build:** Un dépôt frontend volontaire produit une comparaison visuelle desktop/mobile et peut approuver une mise à jour des références sans en faire une exigence globale V1.

**Blocked by:** 32 — Prototyper une incertitude sans réutiliser le code exploratoire; 34 — Bloquer les nouvelles violations Impeccable sur une PR frontend

**Status:** ready-for-agent

- [ ] Une configuration opt-in active une comparaison reproductible à résolution desktop et mobile.
- [ ] Les différences sont consultables en artifact ou commentaire PR.
- [ ] Sans opt-in, aucun check de comparaison visuelle supplémentaire n’est exigé.
- [ ] Une baseline mise à jour est traçable à une révision validée.

**Traçabilité :** user stories US-44 ; tests T-24.
